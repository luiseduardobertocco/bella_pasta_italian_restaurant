# Bella Pasta

Bella Pasta is a mobile-first restaurant landing page built with HTML5, CSS3, Bootstrap 5, and vanilla JavaScript.

## Project structure
- index.html
- css/style.css
- js/translations.js
- js/main.js

## Features
- Responsive design for mobile and desktop
- Four-language support (EN, IT, ES, PT)
- localStorage language persistence
- WhatsApp quick contact
- Bootstrap 5 integration
- Accessible navigation and FAQ structure

## Notes
This project is designed as a professional portfolio landing page for a fictional Italian restaurant.
