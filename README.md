# Bella Pasta

Bella Pasta is a responsive restaurant landing page built as a frontend portfolio project with HTML, CSS, Bootstrap 5, and vanilla JavaScript.

## Preview

Open `index.html` in a browser. Bootstrap, Google Fonts, and food photography are loaded from external CDNs, so an internet connection is required for the complete presentation.

## Features

- Responsive layout with dedicated hero, story, menu, gallery, team, reviews, location, FAQ, and reservation sections
- English, Italian, Spanish, and Portuguese content with saved language preference
- Localized WhatsApp reservation links
- Keyboard skip link, visible focus states, reduced-motion support, and semantic FAQ controls
- Responsive image loading and social sharing metadata

## Portfolio note

This is a fictional restaurant concept. Replace the sample address, opening hours, phone number, WhatsApp number, menu, reviews, and photography with approved business content before publishing for a real restaurant.
